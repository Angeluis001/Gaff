<threat_model>
## Threat Model (ASVS L1)

| Threat | Severity | Mitigation |
|--------|----------|------------|
| `DATABASE_URL` with plaintext credentials committed to git in drizzle.config.ts | CRITICAL | `drizzle.config.ts` reads `process.env.DATABASE_URL!` only — no inline connection string. Verify with `grep -r "postgresql://" drizzle.config.ts` returning zero matches. |
| `.env.local` accidentally pushed to GitHub | HIGH | `.gitignore` must include `.env*.local`. Pre-commit: run `grep ".env.local" .gitignore` to confirm. |
| Sentry DSN exposed in client bundle (allows event flooding) | MEDIUM | `NEXT_PUBLIC_SENTRY_DSN` is intentionally public (Sentry design); rate limiting is enforced at the Sentry project level. Set ingest rate limit to 1000 events/day in Sentry project settings. |
| Temporary `/api/redis-test` and `/api/sentry-test` routes left in production | MEDIUM | Both routes MUST be deleted before the plan closes. Final `<acceptance_criteria>` block explicitly checks their absence. |
| `drizzle-kit push --accept-data-loss` on a populated production database | LOW | Phase 1 is greenfield — Neon database is empty. Flag is safe here. Document that `push` must NOT be used in Phase 3+ on live data. |
| No rate limiting on API routes at the framework level | MEDIUM | `src/lib/ratelimit.ts` is created in this plan. Phase 3 applies it to booking endpoints. Document in `src/lib/ratelimit.ts` with a comment: `// Apply this limiter in Phase 3+ API routes`. |
</threat_model>

`src/lib/db/schema/boats.ts` — `boats` table using `boatCategoryEnum`:
```typescript
import { pgTable, text, timestamp, integer, boolean, decimal, uuid, jsonb } from 'drizzle-orm/pg-core';
import { boatCategoryEnum } from './enums';

export const boats = pgTable('boats', {
  id: uuid('id').primaryKey().defaultRandom(),
  name: text('name').notNull(),
  slug: text('slug').notNull().unique(),
  category: boatCategoryEnum('category').notNull(),
  capacity: integer('capacity').notNull(),
  length: text('length'),
  description: text('description'),
  features: jsonb('features').$type<string[]>(),
  images: jsonb('images').$type<string[]>(),
  priceHalfDay: decimal('price_half_day', { precision: 10, scale: 2 }),
  priceFullDay: decimal('price_full_day', { precision: 10, scale: 2 }),
  captainName: text('captain_name'),
  isActive: boolean('is_active').default(true),
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
});
```
