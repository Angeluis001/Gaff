# Plan 01-01: Scaffold Next.js 15 App with Folder Structure, shadcn/ui, and Type Stubs

## Goal

Scaffold the Next.js 15 application using `create-next-app@15` (NOT `@latest`), install all Phase 1 dependencies, initialize shadcn/ui with the 10 required components, establish the exact folder structure specified in the build pack, and create TypeScript type stubs that downstream phases will fill in. This plan delivers INFRA-01 and INFRA-02 — a clean dev server and a correct skeleton.

<threat_model>
## Threat Model (ASVS L1)

| Threat | Severity | Mitigation |
|--------|----------|------------|
| `.env.local` committed with real credentials | HIGH | `.gitignore` must include `.env*.local` — verify with `grep -r "env.local" .gitignore` |
| `DATABASE_URL` or `SENTRY_DSN` accidentally embedded in source code | HIGH | All secrets read via `process.env.*` only — no hardcoded strings. ESLint `no-secrets` rule catches literals. |
| shadcn/ui `globals.css` overwriting Tailwind config | LOW | Accept — shadcn init modifies `globals.css` by design. Review diff before committing. |
| Stale `create-next-app@latest` installing Next.js 16 | MEDIUM | Command is pinned to `create-next-app@15` — executor must not deviate. Verify with `node_modules/.bin/next --version` after scaffold. |
</threat_model>
